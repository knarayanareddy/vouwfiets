# Vouwloods · Folding Bike Warehouse (Delft)

Bilingual (NL/EN) folding-bike warehouse showroom for a Delft seller. Linked directly from Marktplaats advertisements to expand inventory beyond the two free ad limit.

- **Live URL (GitHub Pages):** [https://knarayanareddy.github.io/vouwfiets/](https://knarayanareddy.github.io/vouwfiets/)
- **Direct Hash Routes:** `#/bike/VL-xxxx` (e.g. `#/bike/VL-2401`)
- **Conversion Funnel:** WhatsApp deep links with pre-filled SKU reference codes (`VL-24xx`).

---

## 1. Quick Preview (Local)

Serve the root directory directly with any HTTP server:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# or npx serve .
```

Open [http://localhost:8080](http://localhost:8080) in your browser.

---

## 2. Managing Inventory (Single Source of Truth)

You only need to edit **`data/bikes.json`**!

- **Single file workflow:** Over HTTP/HTTPS (GitHub Pages and local server), the site loads `data/bikes.json` dynamically.
- **Automated Fallback:** For offline or `file://` viewers, `js/bikes.js` is automatically generated by running:

```bash
./scripts/sync-bikes.sh
```

*(When pushing to GitHub, the `.github/workflows/deploy.yml` action also validates and auto-syncs `bikes.js` automatically!)*

### Stock Rules:
- Pairs are listed as a single entry with `qty: 2` and optional `unitPrice`.
- Reference numbering format: `VL-2401`, `VL-2402`... Next available ref: **`VL-2415`**.
- Real photos live in `images/real/{slug}/`.
- Editorial studio mood shots live in `images/real/studio/` (labeled as *Sfeerbeeld* / atmosphere).

## 3. Live Bid Synchronization (Serverless / Cloud)

Bids are stored in browser `localStorage` by default and seamlessly handed off to WhatsApp.

To enable **real-time live bid synchronization** across all visitors' devices using a free Firebase Realtime Database:

1. Create a free Firebase project at [https://console.firebase.google.com/](https://console.firebase.google.com/).
2. Create a **Realtime Database** (e.g. in `europe-west1`).
3. Set the database security rules:
   ```json
   {
     "rules": {
       "bids": {
         ".read": true,
         "$ref": {
           ".write": "newData.child('currentBid').isNumber() && (!data.exists() || newData.child('currentBid').val() > data.child('currentBid').val())"
         }
       }
     }
   }
   ```
4. Copy your database URL into **`js/config.js`**:
   ```javascript
   bidSync: {
     enabled: true,
     provider: "firebase",
     endpoint: "https://<YOUR-PROJECT-ID>-default-rtdb.europe-west1.firebasedatabase.app/bids",
     pollIntervalMs: 30000
   }
   ```
5. If offline or unreachable, the system automatically falls back to `localStorage`.

## 4. Seller Configuration

Edit **`js/config.js`** to configure:
- WhatsApp phone number (international format without `+`, e.g. `31682580785`)
- Marktplaats profile URL
- Pickup hours and payment options (Tikkie / Cash)
- `demoInventory: false`
